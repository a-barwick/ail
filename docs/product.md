# Product intent

AIL is an executable language for software primarily written and operated by
agents. It optimizes the complete cost of a correct change: context discovery,
consequence analysis, validation, repair, regression prevention, and human
review.

Canonical source remains the durable program. The compiler must expose the
types, effects, authority, dependencies, diagnostics, and revision-bound change
facts that agents and reviewers need; approval must not depend on hidden model
reasoning.

AIL targets greenfield backend services, APIs, workers, command-line tools, and
data-processing applications. The job-service workloads exercise explicit
authority, deterministic effects, schema evolution, atomic validation, and
architecture policy. They do not prove that AIL reduces engineering cost against
other languages; that comparison remains unrun.

AIL is not a prompt format, opaque agent bytecode, or a replacement for human
review. New language capability starts with one blocked, executable workload
and deterministic evidence, not a feature checklist.
